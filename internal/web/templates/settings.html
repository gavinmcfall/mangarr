Bulk Download

Per-provider pacing for the safe-mass-download feature on the Library page.

How long a fed chapter can sit without progress before the detector probes Suwayomi.

After this many re-feeds, mangarr gives up on the chapter and the job auto-completes.

By default, a chapter Suwayomi reports as having 0 pages with queue state ERROR is given up on immediately. Tick this to fall back to the stall timeout instead (useful only if a source occasionally returns 0 pages transiently).

Backoff ladder on Suwayomi HTTP 429: 5s → 15s → 60s → 5min, then mark errored.
